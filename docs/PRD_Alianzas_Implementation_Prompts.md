{
  "title": "Alianzas - Banxico Exchange Rate Integration",
  "body": "## Overview\nImplement integration with Banco de México API to fetch official USD/MXN exchange rates for commission calculations.\n\n## Requirements\n\n### 1. Backend - Banxico Service\nCreate `backend/src/core/servicios/banxico_service.py`:\n\n**API Details:**\n- Base URL: `https://www.banxico.org.mx/SieAPIRest/service/v1/series/`\n- Series ID for USD/MXN FIX: `SF43718`\n- Authentication: Banxico API Token (optional, public series)\n- Response format: JSON\n\n**Class: BanxicoService**\n```python\nfrom datetime import date, timedelta\nfrom decimal import Decimal\nimport httpx\nimport logging\n\nlogger = logging.getLogger(__name__)\n\nclass BanxicoService:\n    BASE_URL = 'https://www.banxico.org.mx/SieAPIRest/service/v1/series/'\n    SERIE_TC_FIX = 'SF43718'  # Tipo de cambio FIX\n    \n    def __init__(self):\n        self.timeout = 30\n        self._cache = {}  # Simple in-memory cache\n    \n    async def get_tipo_cambio(self, fecha: date) -> Decimal:\n        \"\"\"\n        Obtiene el tipo de cambio FIX para una fecha específica.\n        \n        Args:\n            fecha: Fecha para la cual obtener el TC\n            \n        Returns:\n            Decimal: Tipo de cambio USD/MXN\n            \n        Raises:\n            ValueError: Si no se puede obtener el TC para esa fecha\n        \"\"\"\n        # Check cache first\n        cache_key = fecha.isoformat()\n        if cache_key in self._cache:\n            return self._cache[cache_key]\n        \n        # Fetch from API\n        tc = await self._fetch_from_api(fecha)\n        self._cache[cache_key] = tc\n        return tc\n    \n    async def get_tipo_cambio_actual(self) -> Decimal:\n        \"\"\"Obtiene el tipo de cambio más reciente disponible.\"\"\"\n        today = date.today()\n        # Try today, then go back up to 5 days (weekends/holidays)\n        for i in range(5):\n            try:\n                return await self.get_tipo_cambio(today -
