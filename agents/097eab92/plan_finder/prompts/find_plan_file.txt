### Key Findings:

**Root Causes Identified:**
1. **TOKEN_REFRESHED event not handled** - Supabase auto-refreshes tokens every ~55 minutes, but the AuthContext's `onAuthStateChange` listener may not be properly updating React state with the new session
2. **API interceptor session cache staleness** - The apiClient maintains a separate cached session that can become desynchronized from the actual Supabase session
3. **No session validation mechanism** - If the auth state change listener misses an event, there's no recovery mechanism to detect and fix the desynchronization
4. **Profile fetch errors clear auth state** - Transient network errors during profile fetching set `userProfile` to null, making the user appear logged out
5. **No window focus validation** - When users return to the tab after inactivity, expired tokens aren't detected and refreshed
